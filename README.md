# איפה הכסף

אפליקציית מעקב הוצאות פרטית שרצה כולה בטלפון. אין בה שרת ואין בה חיבור לאינטרנט, והנתונים נשמרים רק בדפדפן שבטלפון. המאגר הזה מכיל קוד בלבד, בלי שום נתון אישי.

| קובץ | מה יש בו |
|---|---|
| `index.html` | שלד הדף והגדרות האבטחה (CSP) |
| `app.js` | כל הלוגיקה והמסכים |
| `styles.css`, `fonts.css` | עיצוב וגופנים מוטמעים |
| `lib/xlsx.full.min.js` | ספריית SheetJS לקריאה וכתיבה של אקסל; נטענת רק כשצריך |
| `sw.js` | עבודה בלי אינטרנט, קבלת שיתוף מווטסאפ, עדכון רק באישור |
| `version.json` | מספר הגרסה ומה חדש |
| `tools/release.py` | מעדכן את מספר הגרסה בכל המקומות בפקודה אחת |
| `tests/run_tests.py` | בדיקות אוטומטיות על נתונים מומצאים בלבד |

לפני כל עדכון מריצים: `python3 tools/release.py <גרסה> "מה חדש"` ואחר כך `python3 tests/run_tests.py`.
